👨‍💻 Code Dekhein
/* 18. Yeh CSS ka Comment hai */

.demo-card {

/* 2. Pseudo-class Selector (:hover) */
.demo-btn:hover {
  background-color: #db2777;
  color: white;
}

/* 2. Attribute Selector */
input[type="text"] {
  border: 2px solid blue;
}

13. Shorthand Properties

Har element ek box hota hai (Margin, Border, Padding, Content). Hum Text (color, font-size) aur Backgrounds ko bhi design kar sakte hain. Shorthand property se code chhota ho jata hai (e.g., margin: 10px 20px;).

👨‍💻 Code Dekhein
.box-model-demo {
  /* 3.4 Box Model */
  width: 100%;
  box-sizing: border-box;
  
  /* 13. Shorthand (Margin, Padding, Border) */
  padding: 20px 15px;
  border: 3px dashed #db2777;
  
  /* 3.5 Typography */
  font-family: Arial, sans-serif;
  text-align: center;
  letter-spacing: 2px;
  text-transform: uppercase;

  /* 3.6 Background & 3.7 Effects */
  background: linear-gradient(90deg, #ffe4e6, #e0f2fe);
  border-radius: 10px;
  box-shadow: 0 5px 15px rgba(0,0,0,0.1);
}

3.1 Layouts
7. Display Types
8. Position
9. Overflow
10. Z-Index System

Display (block, inline) element ka nature tay karta hai. Position (relative, absolute, fixed, sticky) uski jagah. Z-index (layer) aur Overflow (scroll/hidden) bahar nikalne wale content ko control karte hain.

👨‍💻 Code Dekhein
.container {
  width: 100%;
  height: 150px;
  border: 2px solid #ccc;
  
  /* 9. Overflow Type */
  overflow: scroll;
  
  /* 8. Position Type */
  position: relative;
}

.floating-badge {
  position: absolute;
  top: 10px;
  right: 10px;
  /* 10. Z-index System */
  z-index: 999;
  /* 7. Display Type */
  display: inline-block;
}

3.2 Flexbox
3.3 Grid

Flexbox single line (Row/Column) alignment ke liye best hai. Jabki CSS Grid ek sath Rows aur Columns (2D layout) dono banane ke liye sabse powerful system hai.

👨‍💻 Code Dekhein
/* 3.2 FLEXBOX (1D Layout) */
.flex-box {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 10px;
}

/* 3.3 GRID (2D Layout) */
.grid-box {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

4. Value Types
11. Units System
3.10 Custom Properties

CSS me 15+ value types hote hain (Colors: HEX, RGB; Units: px, %, em, vh). Variables (--var) CSS ka sabse powerful feature hai jo unlimited (open-ended) values store karne me madad karta hai.

👨‍💻 Code Dekhein
/* 3.10 Variables (Root me define karein) */
:root {
  --main-color: #8b5cf6; /* HEX Color */
  --box-width: 80%;   /* Relative Unit */
}

.custom-box {
  /* Variable ko use karna */
  background-color: var(--main-color);
  
  /* 11. Units (vw = viewport width) */
  width: var(--box-width);
  padding: 2rem; /* Relative Unit */
  border-radius: 10px; /* Absolute Unit */
  color: rgba(255, 255, 255, 0.9); /* RGB Color */
}

5. CSS Functions
6. At-Rules
3.9 Media Queries
14. !important

CSS ab ek math engine bhi hai! calc() aur clamp() functions screen ke hisaab se calculation karte hain. @media At-rule website ko mobile-friendly banata hai. Aur !important rules override karne ke kaam aata hai.

👨‍💻 Code Dekhein
.responsive-text {
  /* 5. Functions (clamp: min, ideal, max) */
  font-size: clamp(1rem, 2.5vw, 2rem);
  
  /* calc() function */
  width: calc(100% - 40px);
}

/* 6. At-Rules & 3.9 Media Query */
@media (max-width: 768px) {
  .responsive-text {
    /* 14. !important Rule */
    color: red !important;
  }
}

15. Specificity System
16. Cascade System
17. Inheritance

Specificity: Inline > ID > Class > Element. Cascade: Agar power same hai, toh jo CSS baad me (niche) likhi hai wo jeetegi. Inheritance: Color parent se child me aata hai, par margin/padding nahi aata.

👨‍💻 Code Dekhein
/* 17. Inheritance Example */
.parent { color: blue; }
/* Child me bhi text blue ho jayega */

/* 16. Cascade Example */
p { color: red; }
p { color: green; } /* Last rule wins (Green) */

/* 15. Specificity Example */
#myId { color: purple; } /* ID ki power Class se jyada hai */
.myClass { color: orange; }

3.8 Transform & Animation
@keyframes (At-Rule)

CSS me motion dalne ke 3 tarike: Transform (rotate, scale karna), Transition (smooth hover effect), aur Animation / @keyframes (looping continuous motion).

👨‍💻 Code Dekhein
.bouncing-ball {
  width: 60px; height: 60px;
  background: #10b981;
  border-radius: 10px;
  
  /* Animation Property */
  animation: bounce 2s infinite;
}

/* @keyframes rule */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { 
    transform: translateY(-30px) rotate(45deg);
    background: #3b82f6; 
  }
}
