Mera Pehla Blog Post

HTML Kya Hai?

HTML ka matlab HyperText Markup Language hai. Yeh kisi bhi website ka base ya skeleton (haddiyo ka dhancha) banane ke kaam aata hai.

Iski Zarurat Kyun Hai?

Bina HTML ke hum browser ko yeh nahi bata sakte ki kon si line heading hai aur kon si line paragraph hai.

Shabdon par zor daalna: Normal text me agar aapko kisi word ko mota (Bold), tircha (Italic) ya uspe highlight karna ho, toh in special tags ka istemal hota hai.
👨‍💻 Code Dekhein
<p>
  Yeh ek normal sentence hai jisme humne ek shabd ko 
  <b>Mota (Bold)</b> kiya hai.
</p>

<p>
  Kisine sach kaha hai: <br> <!-- br tag line todne ke liye -->
  <i>"Koshish karne walon ki kabhi haar nahi hoti."</i>
</p>

<p>
  Is document me <u>important line ko underline</u> kiya gaya hai.
  Aap kisi offer ko <mark>High-light (Yellow backgroud)</mark> bhi kar sakte ho.
</p>

<!-- Blockquote dusro ki kahi baat dikhane ke liye -->
<blockquote>Yeh ek quote box hai, jo articles me accha lagta hai.</blockquote>
👁️ Asal Me Kaisa Dikhega

Yeh ek normal sentence hai jisme humne ek shabd ko Mota (Bold) kiya hai.

Kisine sach kaha hai:
"Koshish karne walon ki kabhi haar nahi hoti."

Is document me important line ko underline kiya gaya hai. Aap kisi offer ko High-light (Yellow background) bhi kar sakte ho.

Yeh ek quote box hai, jo articles me accha lagta hai.
Internet ka main hissa: <a> (Anchor) tag se hum ek page se dusre page ka link banate hain. Aur <img> tag se page par photo lagayi jaati hai.
👨‍💻 Code Dekhein
<!-- Anchor tag (Link). href attribute me URL dete hain -->
<p>
  Zada jankari ke liye humari 
  <a href="https://google.com" target="_blank">Website par jayein</a>.
  <!-- target="_blank" link ko naye tab me kholta hai -->
</p>

<h3>Meri Pasandeeda Photo</h3>
<!-- Image tag ka koi closing tag nahi hota.
     src me image ka path ya URL hota hai. -->
<img 
  src="https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=500&q=80" 
  alt="Laptop par coding karta hua" 
  width="100%"
>
<p><small>(Upar ek image dikhayi gayi hai)</small></p>

Points me baat rakhna: Bina number wali list ke liye <ul> (Unordered List) aur number wali list ke liye <ol> (Ordered List) ka use hota hai. Item jodhne ke liye <li> tag lagate hain.
👨‍💻 Code Dekhein
<h3>Cake Banane Ke Ingredients (Bina Number):</h3>
<ul>
  <li>2 cup Maida (Flour)</li>
  <li>1 cup Cheeni (Sugar)</li>
  <li>Aadha cup Doodh (Milk)</li>
</ul>

<h3>Cake Banane Ki Vidhi (Steps in Numbers):</h3>
<ol>
  <li>Sabse pehle oven ko garam karein.</li>
  <li>Saari samagri ko ek bowl me mix karein.</li>
  <li>Oven me 30 minute tak pakayein.</li>
</ol>

Contact ya Login Form: <form> ke andar hum <input>, <select> aur <button> lagate hain taaki user apna naam, email ya password bhar sake.
👨‍💻 Code Dekhein
<form action="/submit">
  <!-- Text Input -->
  <label for="name">Aapka Pura Naam:</label>
  <input type="text" id="name" placeholder="Jaise: Rahul Kumar" required>

  <!-- Email Input -->
  <label for="email">Email Address:</label>
  <input type="email" id="email" placeholder="abc@example.com">

  <!-- Dropdown (Select) -->
  <label for="course">Course Chunein:</label>
  <select id="course">
    <option value="html">HTML Sikhe</option>
    <option value="css">CSS Sikhe</option>
  </select>

  <!-- Submit Button -->
  <button type="submit">Form Jama Karein</button>
</form>
👁️ Asal Me Kaisa Dikhega
Data ko Excel format me dikhana: <table> ke andar hum <tr> (Table Row) aur <td> (Table Data) ka use karke box format me data show karte hain.
👨‍💻 Code Dekhein
<table border="1">
  <!-- Table Header (Upar ki main line) -->
  <tr>
    <th>Roll No.</th>
    <th>Student ka Naam</th>
    <th>Marks</th>
  </tr>
  
  <!-- Pehli Row (Data) -->
  <tr>
    <td>101</td>
    <td>Aman Sharma</td>
    <td>85%</td>
  </tr>
  
  <!-- Dusri Row (Data) -->
  <tr>
    <td>102</td>
    <td>Priya Singh</td>
    <td>92%</td>
  </tr>
</table>
